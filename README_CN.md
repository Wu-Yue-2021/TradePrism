# 金融工具集 - 中文说明

本项目是一套中文金融/交易记录管理工具集，用于跟踪股票/基金持仓、计算成本均价、分析投资表现。

## 工具列表

### 1. 交易记录管理工具 ([trading_record_manager.py](trading_record_manager.py))

主要的CLI应用，用于管理交易记录。

**运行方式：**
```bash
python trading_record_manager.py
```

**主要功能：**
- 交易记录的增删改查
- 使用"调整成本法"计算成本均价
- 数据筛选和导出（CSV、JSON格式）
- 交割单导入（支持多品种混合）
- 现金记录自动同步
- 批量删除记录
- 品种重命名
- 每周自动备份
- 价格波动敏感性分析（调仓计算时显示不同价格下的结果）
- IRR 内部收益率分析（支持做T交易识别）
- 持仓历史分析（按日期范围查看仓位变化，并标注当日的出入金）
- 颜色层次显示：打印记录时调用 IRR 分析器的匹配引擎，自动匹配买卖堆并区分做T/战略交易（纯做T配对降色不高亮、操作列显示配对记录序号，如 SELL-324）
- 打印记录含费用列（NEW/BUY/SELL 计算手续费，其余操作显示 "-"）
- 数据存储在 `data/trades.json`

**操作类型：**
- `BUY` - 买入（正数持仓）
- `SELL` - 卖出（负数持仓）
- `RESET` - 重置持仓/成本/价格（为IRR连续性插入虚拟交易）
- `NEW` - 建仓买入（从零建立仓位，与 BUY 同样参与匹配与计费）
- `RECORD` - 记录价格但不交易

**成本计算说明：**
本工具使用**调整成本法**，而非加权移动平均成本法。卖出部分成本会按当前卖出价摊销，而非原始买入成本。

**交割单导入的特殊处理：**
- 同一天内卖光（持仓归零）后再买回时，前置成本不重置，而是合并卖出前的总成本与卖出净收入（含费）结转；隔日再买回视为真正平仓，成本重新计算
- 成交价为 0 的股息入账/红利税补缴记录，价格列沿用最近一个有效价格；这类记录只按发生金额调整总成本，不改变持仓数量

**为什么使用调整成本法？**
- 符合投资者心理：卖出后"落袋为安"，剩余持仓的成本自然调整为新基准
- 便于计算"目标成本"：可以通过买卖操作将持仓成本调整到目标价位
- 注意：这可能导致目标价格需要极端数量（包括做空）才能实现

**现金记录自动同步：**
当通过交割单导入交易记录时，系统会自动在「【现金】」品种中创建对应的现金变动记录：
- 买入股票 → 现金减少（现金 SELL）
- 卖出股票 → 现金增加（现金 BUY）
- 现金价格固定为 0.01，份额 = 100 × |发生金额|
- 删除股票记录时同步删除对应的现金记录
- 目前仅交割单导入支持此功能，手动交易暂不支持

**数据存储：**
- 交易记录：`data/trades.json`
- 导出文件：`data/export/`
- 备份文件：`data/backup_YYYY-MM-DD/`（每周自动创建）

### 2. IRR分析器 ([irr_analyzer.py](irr_analyzer.py))

用于计算投资回报率的IRR分析引擎。

**主要功能：**
- `TradeAnalyzer` 类：动态堆匹配识别做T交易 + LIFO匹配战略交易 + 对数域扫描与牛顿法求解 XIRR
- `preprocess_records()`：处理时间过滤，过滤 RESET/RECORD 非交易记录
- `analyze_and_print_irr()`：格式化输出做T交易、战略交易、持仓和贡献百分比
- 手续费自动计算（区分基金和股票，含过户费、印花税，按交易日期分档）

**做T识别算法：动态堆匹配（核心算法）**
- 全部交易读入数组，双向链表维护相邻关系
- 最小堆按时间距离排序，贪心匹配相邻反向对
- 匹配后更新链表，检查新形成的相邻对
- 超时未匹配交易进入战略持仓（LIFO 栈）
- 正T：先买后卖
- 反T：先卖后买（时间方向、资本占用与正T相反）

**为什么使用动态堆匹配而非滑动窗口？**
- 离线处理可获得全局最优匹配（滑动窗口只能看到过去）
- 避免滑动窗口的边界问题（如窗口边缘的匹配决策）
- 代码更简洁，无死循环风险
- 支持交叉匹配开关（`T_allow_cross` 参数）

详见 [做T匹配算法](docs/t_trade_matching_algorithm.md)

**匹配引擎的显示端复用：**
交易记录管理工具在打印记录处（筛选查询、修改/新增、批量删除前的展示，即 `print_records(color_hierarchy=True)`）内部调用 `Display._build_match_info()`：按品种分组，复用 `TradeAnalyzer.run()` 做同一套做T（动态堆匹配）+ 战略（LIFO）买卖堆自动匹配，输出用于颜色层次显示——
- 纯做T配对（未混战略配对）的记录 → 降色不高亮（`DARK_COLOR` 映射）
- 做T + 战略的全部配对关系 → 操作列显示对方记录序号（如 `SELL-324` / `BUY-325等`，多个对方按匹配量降序取最大）
- 混有战略配对的记录保持高亮，便于在记录列表中直观区分做T与战略持仓

**手续费计算：**
| 品种 | 买入费用 | 卖出费用 |
|------|----------|----------|
| 基金 | max(金额×佣金率, 最低费) | max(金额×佣金率, 最低费) |
| 股票 | max(金额×佣金率, 最低佣金) + 金额×0.02%（过户费） | max(金额×佣金率, 最低佣金) + 金额×0.02%（过户费）+ 金额×0.05%（印花税） |

- 佣金率与最低费分两档（2026-07-11 前/后），具体数值见下方配置表；`force_HT=True` 强制按旧费率
- 基金判断：价格 < 5 元 或 代码含 "ETF"

**IRR计算说明（核心算法）：**
- 做T交易：买卖间隔 ≤ window_days（默认3天）
- 战略交易：买卖间隔 > window_days
- XIRR：在 `u = ln(1+r)` 域上扫描定位 NPV 变号区间，再以阻尼牛顿细化（未收敛时二分兜底），默认排除做T交易
  - 改用 u 域的原因是 r 的定义域 `(-1, +∞)` 下界为开区间，迭代越界时 `math.pow` 会抛 domain error
  - 扫描用四层非均匀网格（中间区密、外围疏），参数由 50000 组模拟样本标定，依据见 [推导文档](docs/xirr_grid_method_derivation.md)
  - 现金流多次变号时方程存在多解，`calculate_xirr()` 返回全部实根 `[(r, u), ...]`，报告会给出多解警示
  - 返回值同时带 u 是因为 r 逼近 -100% 时 double 失去分辨力，区间折算一类计算必须走 u
- 贡献度 = (交易盈亏 / 总盈亏) × 100%
- 期望值 = 胜率 × 盈亏比 - (1 - 胜率)


**现金流记录规则：**
- **核心原则**：现金流只在匹配时记录，不逐笔记录，避免不匹配的交易产生幽灵现金流
- 开头无法匹配的 SELL（分析区间前建的仓位）直接跳过
- 三种匹配场景：
  1. **做T匹配**：配对时 BUY 和 SELL 各按自己的时间戳记录现金流
  2. **战略匹配**：SELL 进入战略持仓后 LIFO 匹配 inventory 中的 BUY，匹配时同时记录 BUY 和 SELL 现金流
  3. **终值虚拟匹配**：遍历结束后，剩余 inventory 中未被 SELL 匹配的 BUY，在期末虚拟卖出——先补录每个 lot 的 BUY 现金流，再加终值 SELL 现金流
- 反T（先卖后买）资本占用符号与正T相反，`capital_days` 取负
- `strategic_cash_flows`（exclude_t=True）：只含战略交易 + 终值
- `cash_flows`（exclude_t=False）：含做T + 战略 + 终值

### 3. 组合复盘 ([portfolio_review.py](portfolio_review.py))

跨品种的区间资金效率报告 —— 给定时间区间，把全部持仓品种放在一起看"这笔钱整体赚了多少"。

**入口**：主程序主菜单 → `r. 组合复盘`（可选上月 / 本月至今 / 自定义区间，并逐项确认需要人工指定价格的标的）

**报告结构：**

| 节 | 内容 |
|----|------|
| [1] 全局概况 | 期初/期末总资产、区间总净利（已实现 + 浮动）、综合收益率与平均资本回报率并列、闭环 XIRR、对账差额 |
| [2] 策略拆解 | 战略波段 / 做T 各自的胜率、盈亏比、期望倍、盈利单 vs 亏损单持仓天数、Top-N 盈/亏单；未平仓敞口拆分为[历史遗留底仓]与[本期新建持仓] |
| [3] 标的透视 | 盈利榜 Top-N / 亏损榜 Bottom-N（含 XIRR、TWAC、平均资本回报率、逐笔统计与代表性交易，未平仓的按[历史遗留底仓]/[本期新建持仓]分组给出基数与区间浮动）；其余未上榜标的按区间盈亏逐行列示 |
| [4] 行为风控 | 最大连亏纪录、净值最大回撤（逐日净值曲线，已剔除出入金，附时间段）、单笔最大亏损、账户现金与备付金充足率 |

**核心机制：组合 XIRR 不是各品种 XIRR 的平均**

把所有品种的现金流合并成一条时间序列后重新解 `NPV(r)=0` —— 资金加权是方程自带的性质（每个现金流以自身金额为系数）。举例：小仓短线 +55%、重仓长线 +10%，简单平均 +32.8%，而合并求解得 +9.0%，后者才是账户的真实资金效率。品种间资金流转（卖A买B）在合并序列里自然抵消，时间零点也无需对齐。

**区间口径：期初持仓折叠成一条虚拟 lot**

期初既有持仓聚合为一条 lot（价格 = 期初价、时间 = 区间起点、免买入费）预置进 LIFO 栈底，一次解决四件事：区间盈亏自动以"期初价"为基准（无需重定基）、TWAC 占用基数自动是期初市值、起点现金流自动生成、区间前建的仓不再被静默丢弃。虚拟 lot 直接进栈、**不参与做T匹配窗口**，否则会与区间首日的卖出配成假做T。**XIRR 是例外**：期初持仓不参与 XIRR 那一遍——把它当成"区间起点投入"会让年化时间轴失真（那笔钱实际投得更早），故该指标与单品种 IRR 界面同口径。

**关键指标定义：**

- **TWAC**（时间加权平均占用资金）= Σ(占用基数 × 区间内持有天数) / 区间天数；占用基数对期初持仓取期初市值、对区间内新建取含费成本
- **综合收益率** = 区间总净利 / 期初总资产（含闲置现金）
- **平均资本回报率** = 区间总盈亏 / 组合 TWAC（不含现金）—— 与上者并列，前者看全部资产、后者看实际投出去的钱
- **闭环 XIRR** = 仅已平仓战略波段，本金基数小、含期初建仓，与全账户收益率不可直接比较
- **对账差额** = Δ总资产 − (已实现 + 浮动)：外部资金、NEW 建仓未同步现金、费用按公式估算的口径差
- **外部资金（出入金）** = Δ现金余额 + Σ买入(含费) − Σ卖出(扣费)：买卖证券造成的现金变化被后一项抵消，抵消不掉的即无对应交易的资金进出。这是**实测值而非估计**——对账差额扣掉它只剩费率舍入；同一口径也用于净值回撤剔除出入金、持仓变化界面标注当日出入金
- **现金余额为负**即融资杠杆，总资产与净值曲线都照实相减，不做过滤

**历史价格**：自动推断（取该时点前最近一条记录的价格）+ 手动覆盖；区间内无记录的标的会在报告顶部显式标注，其区间浮动按 0 计（属数据缺失，不是"无波动"）。

引擎在 `portfolio_analyzer.py` 的 `PortfolioAnalyzer`（纯计算、产出字典，可被 Web/API 复用），渲染在 `portfolio_review.py`（纯格式化，无计算无 I/O）；求解器与统计工具仍留在 `irr_analyzer.py`，两者共用。

### 4. K线形态分析工具 ([candle_stick_analyzer.py](candle_stick_analyzer.py))

分析股票K线形态和成交量特征的交互式工具。

**运行方式：**
```bash
python candle_stick_analyzer.py
```

**依赖安装：**
```bash
pip install pandas numpy
```

**主要功能：**
- 导入华泰导出的日线K线数据（GBK编码）
- 开收关系分析：低开高走/低开低走/高开高走/高开低走的概率分布
- 大阳线/大阴线分析（阈值可配置，默认±5%）
  - 次日走势表现
  - 大阳/阴线后连续上涨/下跌的平均天数和最大天数
- 成交量分析：放量/缩量结合涨跌分析
  - 放量上涨、缩量上涨、放量下跌、缩量下跌的次日表现
- 跳空分析：跳空高开/跳空低开
- 影线分析：上影线/下影线比例（相对于实体）
  - 长上影线/长下影线的次日走势
  - 区分阳线和阴线的影线
  - 上下影线都较长的情况

**数据格式：**
```
300738 奥飞数据 日线 不复权
日期 开盘 最高 最低 收盘 成交量 成交额
01/09/2026 21.20 23.65 21.13 22.85 158041090 3574012900
...
```

**分析功能说明：**

1. **开收关系分析**
   - 低开高走：开盘价 < 前一日收盘价 且 收盘价 > 开盘价
   - 低开低走：开盘价 < 前一日收盘价 且 收盘价 ≤ 开盘价
   - 高开高走：开盘价 ≥ 前一日收盘价 且 收盘价 > 开盘价
   - 高开低走：开盘价 ≥ 前一日收盘价 且 收盘价 ≤ 开盘价

2. **大阳线/大阴线分析**
   - 用户可自定义涨跌幅阈值
   - 统计出现后的连续上涨/下跌天数
   - 分析次日走势的平均涨幅和上涨概率

3. **成交量分析**
   - 放量：成交量相比昨天增加且量比大于1（高于5日均值）
   - 缩量：成交量相比昨天减少且量比小于1（低于5日均值）
   - 量价配合：放量上涨、缩量上涨、放量下跌、缩量下跌

4. **影线分析**
   - 上影线比例 = 上影线长度 / 实体长度
   - 下影线比例 = 下影线长度 / 实体长度
   - 用户可自定义影线阈值（默认1倍实体）

### 5. 分时量能分析工具 ([5min_volume_analyzer.py](5min_volume_analyzer.py))

分析5分钟线量能特征的交互式工具。

**运行方式：**
```bash
python 5min_volume_analyzer.py <文件路径> [天数] [-r]
```
- 天数：分析天数（默认4天）
- `-r`：使用相对量能模式（默认绝对量能）

**依赖安装：**
```bash
pip install pandas numpy matplotlib
```

**主要功能：**
- 计算每根5分钟线相对于当日第一根的量能比例
- 按日期分组显示分时量能表格
- 标注高量能K线（🔥 标记）
- 生成可视化图表（首根量能柱状图 + 分时量能折线图）

**数据格式：**
华泰导出的分钟线数据（GBK编码），格式同日线。

## 常见问题

**Q: 为什么卖出后成本均价会变化？**
A: 本工具使用"调整成本法"，卖出时会按卖出价调整成本，而非传统的加权移动平均法。

**Q: IRR分析中的"虚拟交易"是什么？**
A: 当使用RESET操作重置持仓时，为了保持IRR计算的连续性，会在RESET操作和前一笔交易之间插入虚拟交易。

**Q: K线分析工具支持哪些数据格式？**
A: 目前支持同花顺版本华泰证券客户端导出的日线数据格式（GBK编码）。如需支持其他格式，可修改 `load_data()` 函数。

**Q: 如何修改大阳线/大阴线的判断阈值？**
A: 在K线分析工具中选择功能4或8时，会提示输入阈值，默认为5%。可根据需要调整为3%、7%等。
